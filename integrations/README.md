# Integrations

## problem_agent

Copia del package **TAUROS Problem Agent**: verifica se stai risolvendo il *problema giusto* (`PROCEED` / `INTEGRATE` / `REFRAME`).

- Codice: `problem_agent/src/tauros_problem_agent/`
- Usato da: `tauros.problem_bridge` e `POST /problem/analyze`
- Non richiede pip extra se importato via path locale

Documentazione: `problem_agent/README.md`, `THEORY_OF_PROBLEMS.md`, `MANIFESTO.md`.
